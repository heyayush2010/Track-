# Track-
Multi-purpose API monitor 
This software is an API monitor. There is no limit for which API it can use, it is capable of processing of any internal/external API. It can also provide a detailed summary of the API chosen. It reports enough information for many uses. It can help if you are looking to examin problems with certain connections in your computer. This is as it provided the functionality of the API. As well it can help point out causes to high memory/cpu as it reports the memory/cpu as well. It can definately also be used for malware analysis. By detailing the memory/cpu and the actions of the API you can root out malware and examin it closely, as well as indicatiors of the malware's outgoing ports/connections. You can therfore also ofcourse use this tool in a virtual machine. Also to note that there are risks with all API monitors. The security side is thought out carefully and strong enough to combat such risks. In the event of certain malware infections a malicious actor can abuse the api by cloning it's process's. However, the connections in Track are encrypted and have two-step-verification. This makes it highly unlikely for this to happen. Even though, however in the worst possible scenario, please take note of this possibility. That being said there are some important notes. It is guranteed that is is highly unlikely for Track to lead to security incidents I obviously can't dismiss the possiblity of a worst case scenario. Therfore, in the case of this scenario the author is not responsible for any risk's associated with Track. You must also have python installed on your system for this tool to work. Lastly, this tool will prompt you to enter the path of the API to monitor. In different device's this is different so it is up to you to retrieve the path for the API to monitor in order to start the monitoring functionality. This might take some time. If the path is incorrect you won't get a report. You can use the source code or download the code with a built-in gui. This is built only for windows systems.
